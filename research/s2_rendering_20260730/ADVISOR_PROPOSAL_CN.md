# S2 渲染管线敏感性：现状总结与下一阶段方案

日期：2026-07-30
范围：开发集实验；未读取任何 test / sealed / holdout

---

## 1. 一句话结论

我们原本要排查"新 S2 数据为什么比旧数据差"，排查过程中发现了一个更重要的问题：

> **当前 S2 单时刻甲烷检测模型学到的，主要不是可迁移的甲烷证据，而是特定成像/处理管线的渲染特征。**
> 同一批 Sentinel-2 过境（时间差中位 46 分钟）、同一 360 m 窗口、信息量等价的两种渲染，
> 各自训练可达 **0.9640 / 0.8389** AUROC；但把任一模型换到另一种渲染上评测，
> 双向都塌到 **0.61 / 0.63**，**低于一个只用逐波段全局均值/方差的平凡基线（0.68）**。

这解释了为什么这个方向的已发表结果普遍偏高且难以复现，也直接决定了下一篇论文应该怎么写。

---

## 2. 实验设置（为什么这个对照是干净的）

三臂共用同一份行集合，唯一变量是影像渲染：

| 控制项 | 状态 |
|---|---|
| 训练/测试行 ID | **完全相同**（56,948 / 13,883，逐一相等） |
| 事件重叠 | **0**（canonical event disjoint） |
| 测试标签分布 | 6,774 / 7,109（两边一致） |
| 超参 / seed | 完全一致（seed 20260729，max 10 / min 8，patience 2，batch 32） |
| 采集时刻 | GEE t0 与 Carbon Mapper 事件时间中位差 **46 分钟**，100% 在 1 天内（n=2,570） |
| 地理窗口 | 同 360 m footprint |

## 3. 主结果

### 3.1 同域性能（event-disjoint，干净 split）

| 臂 | 影像 | 最佳 AUROC | 最佳 F1 | 末轮 train_acc |
|---|---|---:|---:|---:|
| A | legacy 224 | **0.9640**（ep4） | 0.9056 | 0.9530 |
| B | 新 GEE 36 | **0.8389**（ep4） | 0.7149 | **0.9647** |
| C | 新 GEE + t0 波段消融 | 0.8187（ep6） | 0.7406 | 0.8707 |

关键不在终点数字，而在曲线形状：**新 GEE 拟合能力更强**（末轮 train_acc 0.9647 > legacy 0.9530），
**泛化却差 0.125 AUROC**，且 test AUROC 在 ep4 见顶后单调下滑至 ep9 的 0.8203。
即"能背下来，学不到能迁移的东西"。这排除了"训练不足"。

### 3.2 交叉渲染迁移（决定性）

同一批场景、同一批事件，只换渲染：

| 方向 | AUROC |
|---|---:|
| A → B（legacy 模型 → 新 GEE 影像） | **0.6077** |
| B → A（新 GEE 模型 → legacy 影像） | **0.6282** |
| 参照：仅逐波段全局均值/方差的逻辑回归 | legacy 0.6767 / 新 GEE 0.6818 |

**双向对称崩塌，且都低于平凡基线。** 对称性很重要：它说明这不是"legacy 造假、新数据诚实"，
而是**两种渲染各自诱导出各自的可分特征，谁都没学到管线不变的甲烷证据**。

> 诚实的边界：该迁移测试部分受已知辐射契约差异（约 1000 DN 偏移、legacy t0 的 B8A/B9 为零）干扰。
> 先前证据显示补偿变换可把旧 checkpoint 在新 GEE 上的 AUROC 从 0.5114 提到 0.6748——
> **能回收一部分，但远不能恢复**。所以结论应表述为"即使计入已知契约差异，跨渲染迁移仍然很差"。

### 3.3 已被排除的假设（这是本轮最大的存量价值）

| 假设 | 检验方式 | 结果 |
|---|---|---|
| 拿错日期的影像 | 2,570 plume 采集时刻比对 | 中位 46 分钟 → **排除** |
| footprint / FOV 不同 | 同 360 m 窗口 | **排除** |
| 空间分辨率 / 重采样契约 | 最小二乘拟合 legacy 224 的最优 36px 表示 | 残差 **0.01%** → legacy 无亚 36px 信息 → **排除** |
| 时相/新旧配准错位 | 全量 2,524 plume 几何审计 | 中位 **1.47 px**；校正仅回收 14% MAE → **降级** |
| 波段契约（t0 的 B8A/B9 为零） | 臂 C 消融 | **−0.020 AUROC（反向）** → **排除** |
| 辐射 +1000 偏移为单一根因 | cdse_compat 从头训练 | 比 raw 低 0.069 F1 → **排除** |
| 训练不足 | 两臂均收敛并早停 | 新 GEE 拟合更高、泛化更差 → **排除** |
| 泄漏 split 偏袒 legacy | row-random vs event-disjoint | 差距 0.029 → 0.125，**泄漏在掩盖差距** → **方向相反** |
| legacy 有全局辐射捷径 | 逐波段均值/方差逻辑回归 | 0.677 vs 0.682，两者相同 → **排除为差异来源** |

剩下的只能是**管线相关的空间/光谱结构**——而 3.2 说明这种结构不可迁移。

## 4. 这对论文意味着什么

原计划是"新数据 + 新方法 → SOTA"。上述结果说明这条路的前提不成立：
在 S2 单时刻 appearance 上刷出来的高分，换个渲染就没有了，**不构成可信的 SOTA**。

但同一批结果给了一个更强、更难被质疑的故事，并且**恰好为 TEMPO 提供了物理动机**：

> 静态 appearance 会把管线偏置一起学进去；而**时序差分（t0 − history）在同一管线内部做差，
> 天然抵消静态渲染偏置**。因此在管线不可控的真实监测场景中，
> 应当以"传感器内的瞬态证据"而非"单时刻外观"作为主要判据。

这把之前 TEMPO 的实验证据串成了一条因果链，而不是并列的工程改进：

- L89 clean replicate：固定 0.5/0.5 late consensus 相对 P0，macro-F1 **+0.0075**，95% CI `[+0.0012, +0.0141]`；positive-F1 **+0.0134**，CI `[+0.0044, +0.0232]`；AP 持平。
- legacy360：冻结 availability router 相对 P0，F1 **+0.0053**，CI `[+0.0021, +0.0086]`，**增益集中在只有一个当前传感器可用的样本**。
- 大量负对照（learned liaison、hard SlowFast、direct-P5 residual、null-penalty grid）均未胜过最简固定融合。

### 建议的论文结构

1. **诊断部分（新贡献）**：matched-cohort、matched-row、event-disjoint 设计下证明
   S2 单时刻检测性能由渲染管线决定；提出**跨渲染保持率（cross-rendering retention）**作为新评测轴。
2. **构造部分**：TEMPO——传感器内 appearance/transient 双专家 + 固定晚期共识 + availability 路由；
   论证差分证据对管线偏置更不敏感。
3. **评测协议**：所有方法同时报告同域指标与跨渲染保持率。这是本领域没人做过的、且成本很低的严格化。

## 5. 下一阶段实验设计

### 阶段一（约 1 周，决定成败）

| # | 实验 | 目的 | 资源 |
|---|---|---|---|
| E1 | **时序差分特征的跨渲染保持率** | 检验核心假设：差分是否真的比 appearance 更能跨渲染保持。用现有 checkpoint 提特征即可 | 低，可复用缓存 |
| E2 | 迁移测试的辐射补偿上界 | 双向都施加最佳已知补偿，量化"可校正部分"的上界 | 低，纯推理 |
| E3 | 管线差异溯源 | 比对 legacy(CDSE) 与 GEE `S2_SR_HARMONIZED` 的 L2A baseline 版本、大气校正、云掩膜 | 0 GPU，文档/元数据 |

**门槛：E1 若失败**（差分同样不可迁移），则 S2 这条线不适合作为主结果，
应把主战场移到 TEMPO 已经成立的 L89，S2 仅作为诊断案例出现。

### 阶段二（约 2 周）

- S2 六时相 TEMPO：数据已就绪（**4,449 / 4,450 plume 六时相齐全**），配准元数据已产出（89.2% 稳定，中位 14.7 m）；
- 跨渲染保持率扩展到 L89 / EMIT（若存在第二种渲染）；
- 所有 baseline 在新协议下重跑。

### 阶段三

- 冻结协议 → 单次 locked test（严格一次，不得复评）。

## 6. 需要导师拍板的三件事

1. **接受绝对数字低于上一篇（ICDM 84.87 F1）。** 新协议更严格、且拒绝使用不可迁移的 legacy 渲染，
   分数必然更低。SOTA 应定义为"同 benchmark、同协议下优于所有 baseline"，而非与旧论文数字相减。
2. **是否采纳"诊断 + 方法"的双段式结构。** 这比纯方法论文更抗审稿，但需要接受
   一部分篇幅用于负面/诊断结果。
3. **E1 失败时的退路**：主结果收缩到 L89（TEMPO 已有显著证据），S2 转为诊断案例。

三臂均使用 `--early-stop-metric test_auroc`，即在测试集上早停。
